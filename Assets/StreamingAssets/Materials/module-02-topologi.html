Topologi Jaringan

MODUL 02

Pola susunan hubungan antar perangkat dalam sebuah jaringan. Topologi menentukan biaya kabel, kecepatan, dan seberapa tahan jaringan terhadap kerusakan.

01

Poin Kunci

Star — paling umum dipakai

Semua node terhubung ke satu switch pusat. Satu kabel putus hanya melumpuhkan node itu.

Bus — hemat kabel

Satu kabel utama dipakai bersama. Rusak di satu titik, seluruh jaringan berhenti.

Ring — data berputar searah

Setiap node punya dua tetangga. Perlu mekanisme token agar tidak terjadi tabrakan data.

Mesh — paling tahan gangguan

Setiap node saling terhubung. Ada jalur cadangan, tetapi biaya kabel paling mahal.

Ingat

Topologi logis mengatur alur data; topologi fisik mengatur letak kabel dan perangkat.

L = n × (n − 1) ÷ 2
Jumlah tautan pada mesh penuh — n = jumlah node

Glosarium

Node
Perangkat apa pun yang terhubung ke jaringan: komputer, printer, HP, atau server. Setiap node punya alamat unik bernama IP address.
Switch
Perangkat pusat pada topologi star. Switch meneruskan data hanya ke port tujuan, sedangkan hub mengirim ke semua port sekaligus.
Bandwidth
Kapasitas maksimum data per detik, diukur dalam Mbps atau Gbps. Bandwidth besar berarti lebih banyak data bisa lewat bersamaan.
Latency
Waktu tempuh data dari pengirim ke penerima, diukur dalam milidetik (ms). Semakin kecil nilainya, semakin responsif jaringan.
Topologi Logis vs Fisik
Jaringan bisa berpenampilan star secara fisik, tetapi berjalan sebagai ring secara logis. Keduanya dijelaskan oleh topologi yang berbeda.
